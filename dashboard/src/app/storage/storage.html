Storage

Homestead uses storage that is already mounted. It never formats or partitions a disk. Register a mount you approve, then assign it a class so installs and backups know where to put data.

Register a mount

The mount must be currently discovered, accessible and writable. Labels are lowercase letters, digits and hyphens. Registering an already registered mount renames it.

Assign a class

Database storage needs a local mount. The daemon refuses mounts that are unsuitable for the class and explains why.
