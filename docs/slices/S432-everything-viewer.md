# S432: Everything read-only viewer

ADR-058 section 4 ("What an outsider gets"). Depends on S431. Bridge only; no daemon, API, CLI or dashboard change, so no PARITY change. The public exposure plan and `read_links_not_exposed` (S433), the app link changes (S437, S438) and any app UI are not part of this slice.

## Scope
`GET|HEAD <base>/_homestead/view/<token>`, registered next to the raw route, with a renderer for Tasks list snapshots and Notes pages and a "no viewer" page for everything else.

## Design as built
- `readroute.go`: `serveRead` and `serveView` are two entry points to one `serveLink`, so the method check, rate limit (shared windows with the raw route), double-cost misses, token pattern, `OpenReadLink` (expiry, revocation, purged owner, vanished file), uniform 404 byte for byte, client-address handling and logging are the S431 code. Only the policy headers and the body differ. The log line is `view link id=... status=200 bytes=...` (never the token).
- Headers: `Content-Type: text/html; charset=utf-8`, `Content-Security-Policy: default-src 'none'; style-src 'sha256-<hash of the fixed stylesheet>'; img-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`, `nosniff`, `Cache-Control: private, no-store`, `Referrer-Policy: no-referrer`, `Cross-Origin-Resource-Policy: same-origin`, `X-Frame-Options: DENY`, `X-Robots-Tag: noindex, nofollow`. No cookie, no CORS. The page has one inline `<style>` equal to the constant the hash is computed from, no style attribute, no script, no image, no external reference.
- `viewer.go` `renderViewer(key, value)`: only a `.json` file is parsed (no sniffing); the kind is the JSON `kind` (Tasks) else `format` (Notes) field. Anything else, unparsable JSON or an unknown kind is the "No viewer for this file" page (200). Values over 8 MiB (the store maximum, so a defence in depth) get a "Too large" page.
- Every string passes `vClean` (invalid UTF-8 replaced, control characters other than newline and tab, bidirectional overrides and BOM dropped, rune cap) and then `html.EscapeString`. The JSON is decoded to `any` and read with type-checked getters, so wrong types are ignored, never an error. Go's JSON decoder refuses nesting beyond 10000.
- Tasks: list name, owner, updated time (UTC), tasks open first then done, each in the owner's manual `order`; title, notes (line breaks kept with CSS), a valid due date and time, priority 1-3, up to 20 tags, up to 100 subtasks with done state. Caps: 2000 tasks and 1 MiB of output, then a "longer than the viewer shows" line. `repeat`, `id`, `icon`, `slot` and `completedAt` are not shown.
- Notes: title, published time, outlines in reading order (y then x), up to 200. Each outline's `html` is only tokenized with `golang.org/x/net/html`; the renderer emits tags from its own allowlist (paragraphs and headings as `div`, lists, blockquote, pre, strong, em, u, s, code, sub, sup, mark, br, hr, table cells as spans, links) and re-escapes all text, so no source markup is copied. Open elements are capped at 32, implicit closes (`p`, `li`, `td`) are done by the renderer, `li` outside a list and nested links are flattened. Links only when absolute `http:`/`https:` with printable ASCII and none of `"'<>`\` , with `rel="nofollow noopener noreferrer"`. `img`, `svg`, `math`, `iframe`, `object`, `embed`, `video`, `audio`, `canvas`, `picture` and non-empty `ink` become the "not shown in this viewer" marker; `script`, `style`, `form`, controls and `template` are dropped with their content. Tokenizer buffer 4 MiB and a token budget bound the work.

## Tests
`internal/everything/viewer_test.go`: Tasks and Notes rendering with order, fields and escaping; every page re-tokenized and checked against a closed tag and attribute set (`assertSafePage`); other files and the oversized guard; the viewer and raw route share token rules (byte-identical 404 for unknown, revoked, expired, deleted, malformed and empty, equal to the raw 404 body, no miss logged), one rate limit across both routes, HEAD/405, no token in the log, registration under the base only; 50 hostile HTML inputs (script/handler/javascript:/data: URLs, nested links, 100k-deep nesting, huge attributes, invalid UTF-8, bidi, raw-text elements); 14 hostile snapshots (200k-deep JSON, wrong types, huge numbers, 3 MiB fields, 5000 tasks and outlines); `FuzzViewer` (seeded; 90 s of fuzzing found one link-character case, fixed). `scripts/everything/gate/run_browser_check_viewer.sh`: headless Chrome loads the Tasks and Notes viewer pages for hostile snapshots through the real bridge; zero CSP violations, no script run or present, no sub-request, only http(s) links, and an injected script is refused by the policy (positive control).

## Unproven
No live Caddy or public name (S433); the browser check uses the dev identity on loopback; no check in Firefox or Safari; Notes pages with very large inlined images beyond the 8 MiB file limit cannot exist.
