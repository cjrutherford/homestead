# S440 - Parametric sharing (ADR-058)

## Goal and dependencies
Turn Parametric's part sharing back on with Homestead meaning (ADR-058 slice row "Parametric: enable sharing"). Depends on S425-S429 (people registry, grants, FS sharing), S439 (the shim 404 fix) and the Parametric package (S376).

## What upstream uses (pinned source, read from the archive)
`src/app/share.ts` only: `fs.share(path, {username|email}, 'read'|'write')`, `fs.unshare`, `fs.getShares`, `fs.listShared` (the "Shared with me" list in Open, `src/app/fileops.ts`). No `getReadURL`, no `kv.share`, no `events`, no `perms`, no `appID` use. `ui.showOpenFilePicker` ("Browse Puter...") stays absent and its button is never shown. So this is person-to-person file sharing and needs the sharing switch; there are no read links and the S432 viewer is not involved (`.parametric` files have no renderer and none was invented; an outsider has nothing to open).

## What changed
- `catalog/parametric.yaml`: `HOMESTEAD_EVERYTHING_SHARING: "1"`, description updated. `TestEverythingSharingSwitchIsPerPackage` and the Python switch test now allow Tasks, Circuits and Parametric.
- `scripts/everything/apps/parametric.json` (37 -> 40 patches): the Share command, File-menu entry and "Shared with me" hiding patches are removed; the title-bar patch now hides only the Assistant and GitHub buttons (Share stays); five wording patches in `share.ts` and the command description say Homestead, not Puter. `sdk_surface.refused` is empty, `fs.share/unshare/getShares/listShared` are supported, `ai` and `net` stay disabled.
- `images/everything` regenerated by `sync-context.sh`. No Go, bridge or shim change (S439 already fixed `fs.write` on a revoked share).
- LGPL OpenCascade notice, licence texts and the S423 source offer untouched.

## SDK table (Parametric)
| Call | Where | Result |
| --- | --- | --- |
| `fs.share(path, {username}, 'read'/'write')` | Share dialog | supported; recipient must have signed in to Parametric; unknown name `user_does_not_exist`, self `cannot_share_with_self`, email refused |
| `fs.getShares(path)`, `fs.unshare` | Share dialog list, Remove | supported |
| `fs.listShared()` | Open, "Shared with me" | supported |
| `fs.read/write` on `~shared/<id>` | open, save | supported; read-only refused, revoked refused |
| `fs.rename/delete` on a shared part | Rename | refused for recipients (file grant) |
| `fs.getReadURL`, `kv.share*`, `events.*`, `perms.*`, `appID` | none | not used by the app |
